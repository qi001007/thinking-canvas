# 产品需求：思考画布

## 目标

提供打开即空白的桌面画布，让用户用类似 Excel 的格子承载任意数据，并以自由绘图表达输入、中间状态、关系与输出。用户自行组织内容，软件不推断算法类型。

## 用户场景

用户把数组、单值或其他数据放进表格，并排观察变化前后内容，再用箭头、文字或形状整理思路。支持逐格改值、区域着色、复制和粘贴。

## 需求范围

- Windows 桌面工具，中文界面，默认窗口 1450×900，最小 1100×700。
- 空白启动，顶部文件操作与工具栏，画布可滚动和中键平移。
- 表格支持自定义名称、行列、逐格文本、改名、追加行列、矩形选择、着色、TSV 复制粘贴和独立复制。
- 支持文字、线、箭头、矩形、椭圆和自由画笔。连线端点可以绑定对象或表格单元格。
- 撤销/重做覆盖用户画布修改。JSON 项目保存对象、位置、数据、颜色和锚点；坏文件必须整体拒绝且保留原画布。
- 输入内容仅存文本，不执行表达式。手动用 `Ctrl+S` 保存。

## 明确不做

没有算法模板中心、预填教学案例、代码执行、自动追踪或步骤时间线。上一版围绕具体算法和高斯示例的实现已放入 `.history/`，不再作为当前产品方案。

## 验收标准

首次启动为空白；表格创建、编辑、复制、粘贴、绘图、连线、移动、撤销和项目保存/打开形成连续工作流；核心模型测试和 Tk smoke 可运行。
