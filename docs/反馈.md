## 2026-10-22：批量输入与卡片工具（已完成）

判据与实测：

- 数组批量输入改为代码格式：弹窗显示 `[1, 4, 2, 5]`，实时预览 `1 行 × 4 列`；改为 `[[1, 2], [3, 5]]` 后预览 `2 行 × 2 列` 并能填入得到 2×2 数据。
- 支持 Excel Tab 粘贴与多行方括号；不再用 Tab 作为可见分隔符，避免“空格太长”。
- 卡片按钮接通：真实鼠标点 `+i` 后指针数 1→2；`⋯` 打开批量输入；列表/字典/集合的 `＋` 分别让 items 1→2、entries 1→2、items 0→1。
- `1 × 4` 实际是数组尺寸，不是张量或“SEN”标签；界面已改成 `1 行 × 4 列`。项目目前没有 SEN 标签或张量卡片，张量支持仍在后续路线。
- 设计规范/记忆补充“批量输入用代码字面量、卡片图标必须有动作”。

## 2026-10-23：启动白屏（已完成，v0.3.5）

- 现象：exe 能打开窗口，但空白/未响应，网页内容完全不显示。
- 根因：v0.3.4 给启动错误页加了 `display:flex`，覆盖了 HTML 的 `hidden`；启动成功时错误页没有内容，却作为全屏纸色遮罩盖住整个应用。
- 修复：补 `.boot-error[hidden]{display:none}`；smoke 增加“隐藏错误层计算样式必须是 none”的断言；正常窗口已用真实屏幕截图确认完整渲染。
- 同时清理了 Temp 中 85 个 WebView2 profile（约 1.7 GB），改为固定 profile + 单实例，避免重复实例和 profile 堆积。
