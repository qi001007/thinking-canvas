# 技术文档

## 架构

使用 Python 标准库 Tkinter 和 Canvas 实现一个可滚动画布。`src/main.py` 启动程序；`src/app.py` 管理工具、绘图、编辑、命中、撤销和保存对话框；`src/model.py` 管理无 UI 的项目数据和验证。无网络、无用户代码执行、无应用运行期第三方依赖。

## 项目格式

JSON 根节点 `{ "version": 2, "objects": [...] }`。对象含唯一 ID 和 kind。表格使用 `data: list[list[str]]` 和同尺寸颜色矩阵。自由端点使用画布坐标；绑定端点保存对象 ID，绑定格子时使用 0 起始 row/col。保存先写入同目录临时文件、flush 后原子替换。打开先验证全部对象和锚点，成功后才替换当前项目。

## 坐标、历史和边界

Canvas 的 `canvasx/canvasy` 统一把鼠标窗口坐标变为画布坐标。Canvas 原生滚动条和中键 scan 拖动支持平移；当前没有缩放。用户操作提交深拷贝快照；拖动只在释放时提交，因此每次拖动为一次撤销。表格限制 200 行、100 列，单元格宽 104、高 34。当前没有自动保存。

## 启动与打包

入口文件为 `src/main.py`；源码运行 `python src/main.py`，smoke 用 `python src/main.py --smoke`。`start.cmd` 优先启动旁边的 `ThinkingCanvas.exe`，之后查找 Python。当前已使用保留的 `.build-env` 打包 onefile/windowed exe，文件位于项目根目录，大小为 10,418,704 字节。

可重复打包命令：

```powershell
.build-env\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name ThinkingCanvas --paths src --add-binary "E:/Anaconda/Library/bin/tk86t.dll;." --add-binary "E:/Anaconda/Library/bin/tcl86t.dll;." --add-binary "E:/Anaconda/Library/bin/libcrypto-1_1-x64.dll;." src/main.py
```

构建显式打入 `tk86t.dll`、`tcl86t.dll` 和 `libcrypto-1_1-x64.dll`。验收记录：五项源码测试和 Tk smoke 通过；最终 exe 在 PATH 仅含 Windows 系统目录的环境下运行 `--smoke`，退出码为 0。
