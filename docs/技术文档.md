# 技术文档

## 架构

```
pywebview 桌面壳 (Python)
  └── 本地 HTTP 服务加载 web/
        ├── js/core/   纯数据层（模型、步骤、差异、几何、持久化）
        └── js/ui/     渲染与交互（画布、时间线、检查器、分栏、快捷键）
```

- 桌面壳只负责窗口、原子写入、`boards/` 画板管理和遗留导入/导出接口。
- 前端不使用框架、不需要构建；浏览器和桌面共用同一套页面。
- `web/js/core/` 不访问 DOM，可直接在 Node 中测试。
- UI 的临时状态（当前查看步骤、选中对象、视口、工具）不写入项目文件。

## 数据模型

项目 JSON（`schemaVersion: 1`）：

```json
{
  "schemaVersion": 1,
  "title": "两数之和",
  "createdAt": "...",
  "updatedAt": "...",
  "objects": [],
  "live": { "states": {}, "pointers": {} },
  "steps": []
}
```

- `objects`：持久对象。`array` / `list` / `dict` / `set` / `variable` / `node` 有状态；`sticky` / `text` / `function` / `connector` / `pen` / `shape` 是标注或布局。`pointer` 是持久对象，但它指向哪里属于状态。
- `live.states`：当前可编辑状态，按对象 ID 存。
  - array：`{ data: string[][], marks: string[][] }`
  - list：`{ items: string[], marks: string[] }`
  - dict：`{ entries: [{ key, value }] }`
  - set：`{ items: string[] }`
  - variable / node：`{ value: string }`
- `live.pointers`：指针 ID → `{ targetId, row?, col?, index? }`。
- `steps[]`：`{ id, title, note, createdAt, objectIds, states, pointers }`。每一步保存当时存在的对象 ID、所有状态和指针位置。
- 布局（`x/y`、卡片尺寸）和标注不属于步骤状态；它们在所有步骤间保持不变。

## 步骤与差异

- “当前”是 live 草稿，可自由改；点“记录一步”把当前状态冻结成新步骤。
- 查看历史步骤时只读；对象位置也不可拖动；回到当前继续编辑。
- 差异比较相邻快照：数组逐格、列表逐项、字典按 key、集合按增删、变量/节点按值、指针按目标。
- 数组同时比较标记（marks）：数据没变但标记变了也会提示“标记变化”。
- 渲染时差异优先于语义标记：查看历史步骤时，变了的格子显示琥珀色，即使它同时有绿色/蓝色标记。
- 指针在历史步骤中按快照位置显示；移动到别的格子时，时间线显示指针变化。

## 交互与几何

- 画布是无限平移/缩放平面；对象用绝对坐标，连线在屏幕坐标 SVG 层渲染（避免缩放导致线宽变化）。
- 数组卡片几何由 `web/js/core/geometry.js` 统一计算，UI 的 CSS 尺寸必须与它一致。
- 连线端点可以绑定对象、数组格子、列表项或字典行；对象到对象的连线会自动选择朝向对方的边。
- 指针胶囊是屏幕层 DOM，拖动时用 `elementFromPoint` 找到目标格子/列表项/字典行/节点；目标会显示彩色描边。
- 吸附参考线在拖动时计算边缘/中心对齐，阈值按缩放换算。
- 自动 fit 不放大超过 100%，避免非整数 CSS 缩放把表格文字和 1px 网格线拉糊；留白按视口取 56–90px，窄窗给画布更多可用面积；文档截图用 2x deviceScaleFactor。
- 示例画板采用纵向列（函数卡、不变量、数组、变量），在 1100px 宽窗口仍能保持约 81% 的可读缩放；默认 1450×900 下约 99%。

## 界面布局与分栏

- 工作区是 7 列 CSS Grid：画板栏、分隔条、工具栏、分隔条、画布、分隔条、检查器；底部时间线跨画布+检查器。
- 画板栏与工具栏各自内部滚动，互不挤压；画板栏 = 固定栏头（标题/数量/新建/收起）+ 搜索 + 列表 + 固定栏底（目录/示例）。
- 分栏宽度在 `web/js/ui/panes.js` 统一处理：拖动、键盘方向键、双击复位、宽度持久化、窄窗压缩。
- 画板栏最低压缩为 44px 图标轨道，工具栏最低压缩为 46px 图标轨道；点击画板轨道恢复上次宽度。窄窗按检查器 → 画板 → 工具的顺序压缩，画布至少保留 360px。
- 分栏宽度存在 `boards/.ui-state.json`（源码运行=仓库根目录；打包=exe 旁边；smoke/测试用临时画板目录），与画板数据同目录。读取失败或超过 1.5 秒就使用默认宽度，不阻塞启动。
- 状态提示是画布内的浮层（`status-float`），启动 6.5 秒或操作后约 3 秒自动隐藏，可点 × 关闭；隐藏时 `inert`，不进入 Tab 顺序。
- 滚动条统一 8px、圆角、token 颜色；默认透明，仅在对应栏/容器 `:hover` 时显示。

## 画板存储与文件

- 所有画板统一放在应用旁边的 `boards/`（源码运行=仓库根目录；打包=exe 旁边）；每个画板一个 `board-<id>.tcanvas.json`，标题存在内容里。
- 当前画板每次修改后自动保存；新建/切换/删除都在左侧画板栏完成；删除移到 `boards/.trash/`，可手动恢复。
- 旧 `%APPDATA%/ThinkingCanvas/session.json` 在首次列出画板时迁移：有内容就生成一个画板文件，空会话直接移除。
- 保存：先验证 JSON 结构，再写同目录临时文件、`fsync`、`os.replace` 原子替换。
- 打开：完整解析/验证成功后才替换当前画布；失败保留原画布并提示。
- 启动：列出 `boards/`，按修改时间打开最近画板；没有画板时自动新建一个。
- 桌面桥接：前端轮询 `window.pywebview.api.load_session` / `app_info` 确实可调用后才使用桌面 API；不会在 API 未挂载时误判。
- 画板 API：`boards_info` / `list_boards` / `create_board` / `save_board` / `load_board` / `delete_board` / `open_boards_folder`；所有路径限制在 `boards/` 直接子文件，拒绝目录穿越。
- UI 状态 API：`load_ui_state` / `save_ui_state`；单文件 `boards/.ui-state.json`，限制 64 KB，原子写入；只存分栏宽度等界面偏好，不存画板内容。

## 运行与打包

- 运行源码：`python app\shell.py`（需要 `pywebview`）。
- 开发预览：`python scripts\serve.py`，浏览器打开 `http://127.0.0.1:8765`；开发服务器禁用缓存。
- 打包：`.build-env\Scripts\python.exe scripts\build_exe.py`，或手写 PyInstaller 命令。
- 单文件 exe 约 12.8 MB（v0.3.0：12,821,954 字节；SHA-256 `6a1db4e86f8ab40d4aa3d3514ee167550828956ef69ee34dad27045622552723`）；Windows 需要 WebView2 Runtime（通常已预装）。
- Anaconda 环境打包时 PyInstaller 可能漏掉 `libcrypto-1_1-x64.dll`、`libssl-1_1-x64.dll`、`ffi.dll`；构建脚本会自动从 `sys.base_prefix/Library/bin` 带上。
- 窗口版 exe 的 `--smoke` 结果同时写到 `%APPDATA%/ThinkingCanvas/smoke.json`，因为 windowed 进程没有可靠 stdout。

## 测试与门禁

- `node --test tests/core.test.mjs tests/panes.test.mjs`：模型、快照、差异、序列化、几何、解析、分栏宽度/窄窗压缩。
- `python -m pytest tests/test_api.py -q`：画板 CRUD、旧会话迁移、坏输入、UI 状态存取与大小限制。
- `python app\shell.py --smoke`：真实 WebView2 启动 + 前端断言（含双栏、搜索、状态浮层、分栏缩放、UI 状态往返）+ 桌面 API 回报。
- 本机 GPU 在窗口被遮挡时会让 WebView2 smoke 卡在窗口创建；用 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--disable-gpu python app\shell.py --smoke` 复测。应用本身不需要该变量。
- `python -m compileall app`：Python 语法门禁。
- UI 改动需额外做浏览器/窗口截图验收；只看类型检查不算完成。

## 限制

- 数组最多 100 行 × 60 列；集合/字典/列表最多 300 项。
- 自由画笔不做平滑拟合；大量对象时未做虚拟化。
- 历史步骤只读；可从时间线 × 或 Delete 删除；暂不支持编辑旧步骤自动分叉。
- 界面文案以 `前端设计规范.md` 为准；说明性内容放帮助层，不常驻主界面。
- 没有自动布局、代码执行或算法模板。
